# Модель скоринга

Файлы: `ml/dataset.py`, `ml/features.py`, `ml/train.py`, `ml/predict.py`.

- Обучение использует синтетические данные и сохраняет pickle плюс метрики.
- Проверять leakage: признаки не должны использовать метки либо данные, которые
  появляются после момента скоринга; статистики должны вычисляться только на train.
- Инференс подавляет ошибки и откатывается к эвристике. Любая оценка качества должна
  учитывать возможное расхождение train и serving.
- Не переобучать и не перезаписывать артефакты без необходимости: это создаёт шумный
  бинарный дифф и не входит в две требуемые бэкенд-правки.
