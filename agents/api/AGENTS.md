# API и SQLite

Файлы: `api/main.py`, `api/ingest.py`, `api/reporting.py`, `api/auth.py`, `api/db.py`.

- Приём: `POST /ingest` создаёт `events` и `queue` в одной транзакции.
- Отчёты читают `scores` по `processed_at`, а не по времени исходного события.
- Заявленный ключ идемпотентности — `(source, external_id)`; это должно быть
  обеспечено базой, а не только предварительным `SELECT`.
- Время в хранилище по контракту — UTC. Использовать timezone-aware UTC и единый
  формат при любой точечной правке времени.
- Авторизация сейчас заглушка на `X-User-Id`; не расширять её без явного решения,
  но фиксировать последствия в отчёте.
