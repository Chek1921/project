# Веб-панель

Файлы: `web/src/`; эталон и обязательный минимум — `web/design/mockup.html`.

- Не добавлять UI-библиотеку: макет намеренно реализуем обычными CSS-токенами.
- Обязательны: карточки метрик, согласованные форматы чисел, loading/empty/error,
  адаптив, видимый `:focus-visible`, экспорт.
- Дата из `toISOString()` выражена в UTC; сверять её с выбранной локальной датой.
- Запросы должны обрабатывать HTTP-ошибки и не позволять устаревшему ответу затереть
  текущие фильтры.
- Таблица должна быть доступна на узком экране через внутреннюю прокрутку.
